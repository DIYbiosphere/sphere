DNA My Name is a free educational web tool that converts a name into a fictional DNA sequence. Each letter is mapped to an amino acid, then to a matching codon from the standard genetic code (for example, "Alex" becomes GCA CTC GAG GGA). A "shuffle" button picks different codons for the same amino acids, illustrating the redundancy of the genetic code, and two names can be compared side by side.

The site also includes an explanation of how the conversion works, a full 64-codon table, an FAQ and a page for educators. It describes itself as a playful reverse-mapping demonstration, not real genomics or a genetic test.
